# Authors and Contributors

`powerpack-mcp` is an **experimental, unsupported** project. This file is an attempt to give recognition for **those who have contributed** in some form or another to work that has either become or supports this final product. That is a statement of fact about the work. It is deliberately **not** a statement about who supports, maintains, or answers for the software — see the status notice in [README.md](README.md) and the project licence for that.

This MCP Server release is the last product of Team Tetris.  It merges multiple previous fractured stdio MCP server repos down to one.  Tetris changed the delivery method from stdio to streamable HTTP transport and created nginx configurations so that the MCP server can be hosted on either AIO or CDB development stacks (further enhancements added in this MCP server are covered in the documentation). Many bodies of work made this server possible:

1. the MCP server itself, in this repository;
2. several MCP servers in differing states whos features fed into this larger product
3. the enabling changes to **Skylar One (SL1)** that gave the server something to call.
4. the Low Code Tools library that enables the patterns leveraged and implemented

Contributors to all of the above are listed below. Emails are omitted throughout; contributors are reachable through LinkedIn if they choosen to have their LinkedIn bookmark listed.
